# E-commerce-storefront - E‑commerce Frontend Mockup

A responsive, client‑side e‑commerce storefront built with **HTML, CSS, and JavaScript**.  
Features a product catalog with categories (Men, Women, Accessories), a shopping cart (add/remove, quantity controls), localStorage persistence, and a mock checkout.

## ✨ Features
- Product grid with 9 items (Men, Women, Accessories)
- Category filter buttons (All / Men / Women / Accessories)
- Add to cart, update quantity, remove items
- Cart drawer (slide‑in) with real‑time total
- Cart data saved in browser localStorage
- Mock checkout alert (frontend demo)
- Fully responsive (mobile friendly)
